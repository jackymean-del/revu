# P0 Pilot: acceptance tests and what proves them

Release P0 (blueprint Part 8) as it is built, in the same form as
[v1.md](v1.md). Each row names the check that proves it; all run in CI and
with `make test`.

| Test | What it asks | Proved by | Status |
|---|---|---|---|
| AT-DB-01 | Every number on a dashboard equals the length of the list it opens | `backend/internal/dashboard/dashboard_test.go` opens every tile of every role and compares; the tile and its list run the same query. On screen, `e2e/tests/dashboard.spec.ts` | Done (P0.1) |
| AT-DB-02 | A teacher's dashboard holds only the classes assigned to them | `dashboard_test.go` (two teachers, three sections, two branches: each sees their own; tiles of others answer 404) | Done (P0.1) |
| AT-DB-03 | View-only sees counts and status, never names | `dashboard_test.go` (no tile is listable; every list answers 403); `dashboard.spec.ts` (no tile opens) | Done (P0.1) |
| Part 76.3 | At most six tiles, exceptions first, one action each, phone layout, print view for leaders | `dashboard_test.go` (order and limit); `dashboard.spec.ts` (order, action link, two tiles to a row at 375 px with no sideways scroll, print view) | Done (P0.1) |
