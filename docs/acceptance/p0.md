# P0 Pilot: acceptance tests and what proves them

Release P0 (blueprint Part 8) as it is built, in the same form as
[v1.md](v1.md). Each row names the check that proves it; all run in CI and
with `make test`.

| Test | What it asks | Proved by | Status |
|---|---|---|---|
| AT-DB-01 | Every number on a dashboard equals the length of the list it opens | `backend/internal/dashboard/dashboard_test.go` opens every tile of every role and compares; the tile and its list run the same query. On screen, `e2e/tests/dashboard.spec.ts` | Done (P0.1) |
| AT-DB-02 | A teacher's dashboard holds only the classes assigned to them | `dashboard_test.go` (two teachers, three sections, two branches: each sees their own; tiles of others answer 404) | Done (P0.1) |
| AT-DB-03 | View-only sees counts and status, never names | `dashboard_test.go` (no tile is listable; every list answers 403); `dashboard.spec.ts` (no tile opens) | Done (P0.1) |
| Part 76.3 | At most six tiles, exceptions first, one action each, phone layout, print view for leaders | `dashboard_test.go` (order and limit); `dashboard.spec.ts` (order, action link, two tiles to a row at 375 px with no sideways scroll, print view) | Done (P0.1) |
| AT-AP-02 | A class with an unassigned choice shows a completeness warning, and that student's result for the group is blocked with the reason | `backend/internal/choices/choices_test.go` (the completeness check names who has not chosen); `dashboard_test.go` (the missing choices tiles); `e2e/tests/choices.spec.ts` (the warning on screen) | Warning done (P0.2); the blocked result comes with results in P0.4 |
| AT-AP-09 | Changing a choice mid-year keeps the old one in history and applies the effective date | `choices_test.go` (the old choice holds until the day before, the new one from the date, audited) | Choices done (P0.2); old marks in history come with marks in P0.3 |
| AT-AP-11 | Another institution cannot read or change subject groups or choices | `choices_test.go` (B sees only its own groups; A's section is 404; A's group is unknown to B); `rls_test.go` covers the new tables | Done (P0.2) |
| Part 74.1 | Groups with a rule, bulk assignment, import by admission number, copy from last year, the class teacher where permitted | `choices_test.go` (rules, range limit, bulk, correction, ending, copy, import twice, who may change); `choices.spec.ts` (one by one, in bulk, by preset, the class teacher's menu) | Done (P0.2) |
