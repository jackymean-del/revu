# v1 Foundation: acceptance tests and what proves them

Each acceptance test of release v1 (blueprint Part 8, v1) and the decisions
register (Part 65) that v1 touches, with the check that proves it. Every
check runs in CI on each push (`.github/workflows/ci.yml`) or nightly
(`nightly-checks.yml`), and locally with `make test`.

| Test | What it asks | Proved by | Status |
|---|---|---|---|
| AT-v1-01 | A user of organisation A asking for any id of organisation B gets 404, for every table, through the application role | `backend/internal/db/rls_test.go` TestNoCrossTenantAccess walks every table with row-level security as `revu_app`: no rows of B are visible and none can be moved into B; with no organisation set nothing is visible. At the API: `tenant_test.go` (another organisation is 404), `structure_test.go` and `terminology/handler_test.go` (B's ids are unknown or 404) | Done at the database for every table; the generated per-endpoint suite of Part 9.1 comes with v2 |
| AT-v1-02 | The application role cannot bypass row-level security and owns no table | `rls_test.go` TestAppRoleIsFencedIn; the server refuses to start in production through a role that could | Done |
| AT-v1-03 | Switching preset from school to university changes every visible word | `frontend/terminology-verify.mts`; browser journeys `words.spec.ts`, `structure.spec.ts` and `people.spec.ts` show the university's words from the same screens | Done |
| AT-v1-04 | A literal institution word in a component fails lint | `frontend/eslint-rules/institution-words.js`, proven on planted components by `terminology-verify.mts` | Done |
| AT-v1-05 | A branch coordinator cannot read another branch's sections; a teacher cannot edit structure | `backend/internal/auth/policy/policy_test.go` (every matrix cell against the blueprint, and scenarios); `structure_test.go` (branch administrators only inside their branch) | Done |
| AT-v1-06 | 500 students with 5 invalid rows: 495 created, a downloadable error report, repeatable without duplicates | `backend/internal/people/people_test.go` TestImportFiveHundredStudents | Done |
| AT-v1-07 | Editing a student name writes one audit entry with before and after | `people_test.go` TestStudentsAndContacts | Done |
| AT-v1-08 | The setup steps take a new organisation to a year, periods, levels, sections and subjects by keyboard alone | `e2e/tests/setup.spec.ts` (keyboard only, against an in-memory API); each endpoint it uses is tested on the real database in Go | Done |
| AT-v1-09 | Initial JavaScript for every route under 200 KB gzip | `frontend/bundle-verify.mts` (131 KB at v1.11); every other screen is a lazy chunk of at most 7.2 KB | Done |
| AT-v1-10 | Tests pass from a clean clone with docker compose up, make migrate, make test | CI runs everything from a clean checkout on a fresh PostgreSQL 18; `make test` runs the same checks locally | Done in CI; `make` is not installed on the Windows machine, so the Makefile target itself is run in CI style by hand there |
| AT-P-01 | A first-time administrator completes setup without help | `setup.spec.ts`; the pilot observes real administrators (Part 66.4) | Done in the journey; pilot observation pending |
| AT-P-02 | A class list from Excel shows a validation report and no student is created twice | `people_test.go` TestImportExcel and the repeat import | Done |
| AT-D-01 | A dependency on Chi, React Router, goose, Vitest or AG Grid Enterprise, or a direct grid import, fails the build | `frontend/deps-verify.mts` | Done |
| AT-D-02 | The cross-tenant suite covers every table with org_id | `rls_test.go` reads the table list from the database, so a new table is covered at once and fails until seeded | Done |
| AT-D-03 | The style check scans the blueprint and REVU.md for em dashes | `frontend/style-verify.mts` | Done |
| AT-GR-01 to 03, 07 | Template, upload preview, blanks never zero, paste follows upload rules | `frontend/datagrid-verify.mts` (wrapper rules, D20) | Done for the rules; the grid itself is P0.3 |

## Open at the end of v1

- The generated per-endpoint cross-tenant suite (Part 9.1) grows with v2's endpoints.
- Confidentiality by default (Part 77) is in the permission matrix; its grants, access log and ownership transfer are v2.20.
- Clerk webhook endpoint and signing secret are set on deploy (Railway), and organisations are linked to Clerk organisations then.
- Moving students at year end is previewed; applying it comes with the year-end tools.
